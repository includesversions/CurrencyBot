# CurrencyBot

A Telegram bot that retrieves the prices of 6 currencies every 1 hour and publishes them to a Telegram channel.

## API

This project uses the [Iran-Market API](https://github.com/iran-market/iran-market.github.io) to retrieve currency prices.

## Dependencies

### Newtonsoft.Json

Used for JSON deserialization and processing API responses.

[GitHub Repository](https://github.com/JamesNK/Newtonsoft.Json)

### Telegram.Bot

Used to interact with the Telegram Bot API and publish messages to a Telegram channel.

[GitHub Repository](https://github.com/TelegramBots/Telegram.Bot)
